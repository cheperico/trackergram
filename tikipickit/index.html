❓ Ayuda

🔧 ¿Qué es TikiPickIt?

Aplicación web progresiva (PWA) para cargar datos en trackers de TikiWiki directamente desde el navegador o el celular, con o sin conexión a internet.

🔑 Primeros pasos

  1. Configurar conexión — En ⚙️ Configuración poné la URL de tu TikiWiki (ej: https://wiki.ejemplo.org).
  2. Autenticarte — Usá OAuth2 (recomendado, con "Iniciar sesión con TikiWiki") o un Token manual desde tu perfil de TikiWiki (Admin → API Tokens).
  3. Seleccionar trackers — Elegí qué trackers se muestran en tu dashboard desde la sección "Trackers visibles".
  4. Cargar datos — Tocá una tarjeta de tracker, completá el formulario y guardá.

📶 Sin conexión

TikiPickIt guarda los datos localmente aunque no tengas internet. Al recuperar la conexión, los datos se sincronizan automáticamente con TikiWiki.

Los items pendientes aparecen con una cuenta en el badge del header y en el dashboard. Podés sincronizar manualmente desde 📋 el dashboard.

⚠️ Errores y reintentos

Si un item falla al sincronizar, pasa a la ❌ vista de errores. Podés reintentarlo individualmente o todos juntos.

Cuando hay más de 3 reintentos fallidos, el item se descarta para no bloquear la cola.

🔐 Seguridad

Los tokens OAuth2 se guardan en IndexedDB (cifrado del navegador). El token manual expira a los 7 días por seguridad. Siempre usá HTTPS para conectarte a TikiWiki.

📱 Instalación PWA

En Android (Chrome): menú ⋮ → "Instalar aplicación". En iOS (Safari): botón Compartir → "Agregar a pantalla de inicio".
